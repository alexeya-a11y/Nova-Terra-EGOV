# Nova Terra — экономический портал

Интерактивный сайт проекта по экономике (MYP Economics, Unit 1): изолированный остров Nova Terra в Minecraft с населением 750 человек и собственной валютой Terra Coin.

**Команда The Balance Builders:** Алексей Абдуннур, Ерқайнар Жомарт, Құмар Рамазан, Елеу Ерелхан.

## Разделы
1. Главный экран
2. Экономика острова — интерактивные цепочки (продовольствие, строительство, вода, энергия, топливо)
3. Terra Coin — правила валюты, примеры операций и «Субботний рынок»: покупка за Terra Coin с разбором, куда уходят монеты
4. Город — интерактивная карта острова (21 объект, масштаб, слои, вид «Схема» и «Изометрия», карточка объекта: кто работает, что получает, что даёт) и скриншоты Minecraft-проекта
5. Промышленность — мукомольный завод и добавленная стоимость
6. Энергия и оборона — две АЭС, угольная и нефтяная вышки, хранилище ресурсов, военная база, модель «пушки или масло»
7. Симулятор «Что произойдёт, если исчезнет один ресурс?»
8. Кабинет Совета — симулятор экономики: население, урожайность, общественные дни, резерв, три кризиса и предупреждения
9. Экономические проблемы
10. Будущее Nova Terra (предложения)
11. Dashboard показателей
12. Тест «Проверь себя»
13. Итоговый экономический цикл

Кнопки в шапке: «День / Ночь» и «Презентация» (на весь экран, крупный текст, стрелки ← → листают разделы, Esc — выход).

Сайт работает на трёх языках: русском, английском и казахском. Язык переключается кнопками RU / EN / KZ в шапке и запоминается; ссылка с `?lang=en` или `?lang=kk` сразу открывает нужный язык.

Все числа в симуляторе и на рынке — условные единицы учебной модели, а не фактические данные острова.

## Как опубликовать на GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save.
Через минуту сайт будет доступен по адресу `https://alexeya-a11y.github.io/Nova-Terra-EGOV/`.

## Переводы
Русский текст — исходный. Переводы лежат в таблице `TR` в начале скрипта в `index.html`: `"русская строка": ["English", "Қазақша"]`. Если добавить на страницу новый русский текст без строки в `TR`, на других языках он останется русским; команда `ntMissing()` в консоли браузера покажет такие строки. Для казахского подключены другие шрифты (Tiny5, Onest, IBM Plex Mono), потому что в основных шрифтах сайта нет казахских букв.

## Файлы
- `index.html` — весь сайт (HTML, CSS и JavaScript в одном файле)
- `town-1.jpg`, `town-2.jpg`, `town-3.jpg` — скриншоты Minecraft-проекта
- `*.png` — исходники пиксельных текстур; в `index.html` они уже встроены, странице эти файлы не нужны
